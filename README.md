# Boopstick

A poking stick for overconfident agents.

Boopstick is a planned TypeScript tool for checking explicit UI obligations using observations supplied by existing testing tools. It is not artificial vision and does not certify an entire UI.

**Readiness work only:** no comparator package, collector or installable skill is released here. The maintainer accepted the scope and gave execution go-ahead; owner license approval and parent review of the audited source/prose selection and allowlist are complete. Final parent document review and explicit Phase B assignment precede import. Native/browser collection, merges, release and consumer cutover retain separate approval gates.

- [Proposed behavior and support boundaries](specs/boopstick.md)
- [Migration plan and readiness gates](plans/extract-boopstick.md)

The target is ordinary named tests: selective local feedback, complete CI accounting, and clear distinctions between synthetic component-test data, real browser observations and real native observations.

No concrete contrary third-party notice was found in the selected closure; new contradictory findings hold or exclude affected material. Uncleared third-party material, private application assets and private history remain excluded. This is not blanket rights clearance or registry-release approval.
