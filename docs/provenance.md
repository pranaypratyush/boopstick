## Derivation boundary

- Core derivation preserves exact 3.1 admission/evaluation semantics; changes are limited to packaging-required relative ESM import suffixes and stale version-header wording. Package entrypoint, offline CLI, compiled distribution and packaging metadata are new integration glue, not inherited collector functionality.
- The checker adaptation retains 19 authored cases and 49 independent cases, removes the obsolete evaluator/mode dependency and consistently replaces product-themed authored labels without changing identity/equality/mismatch relationships. Independent oracle JSON is selected for byte-exact retention; expected values are not regenerated from this implementation.
- The canonical contract in the skill bundle is newly reconciled against current wire validators and evaluator, including optional/default fields, unknown-field handling, exact 3.1 browser-provider admission, precedence and reports. Earlier 3.0 text is historical semantic input, not relabelled as a current schema. CLI behavior is a new package contract.
- The standalone skill adapts only selected generic authoring/evidence guidance. It removes host-policy, private-source and provider-specific environment dependencies. The skill's contract and evidence references are self-contained within its directory; there is one canonical contract, not a second schema document.

## Independent expectations and historical labels

The source construction account attributes the 49 oracle cases to independent derivation from the frozen contract/formulas and retained input facts, without consulting the successor implementation, checker output or comparator execution. That is the recorded authorship method, not a claim that hashes prove independence. Literal projections specify aggregate status/counts and sorted assertion outcomes, including refusals and null measurements; they are not golden reports generated from the new implementation.

The frozen dataset contains earlier-version headers. The adapted checker performs explicit in-memory header derivation for current 3.1 replay and preserves intentional incompatible-version negatives. It does not rewrite the frozen JSON, ship an old evaluator or regenerate its predictions. Embedded historical relative fixture/provenance labels are inert attribution, not filesystem dependencies on an excluded checkout. Historical inputs, formulas and labels do not establish live capture truth.

Private application assets/dependencies/collectors/raw evidence, unrelated orchestration, historical runtimes, private plans/review records and machine verification receipts remain excluded. No source verification receipt is presented as a destination result. Creation of this package/skill material is not proof of destination correctness, fresh independent skill consumption, neutral browser/Android qualification, release approval or successful consumer migration; those require their own executed evidence and authority.
